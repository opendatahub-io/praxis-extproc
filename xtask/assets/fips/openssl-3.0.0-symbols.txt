# The OpenSSL symbols the shipped praxis-extproc binary is allowed to import
# from the system libcrypto/libssl under the `OPENSSL_3.0.0` version, one per
# line. `cargo xtask fips report` fails on any imported `@OPENSSL_3.0.0` symbol
# not on this list, so a new, unreviewed call into OpenSSL is caught before it
# ships.
#
# Blank lines and lines beginning with '#' are ignored. To regenerate the set a
# binary actually imports:
#
#   readelf --dyn-syms BINARY | awk '/@OPENSSL_3.0.0/ {sub(/@.*/,"",$8); print $8}' | sort -u
#
# Add a symbol here only after confirming the OpenSSL call it names is
# appropriate for the FIPS build.
